## 2. Tujuan Bug Report

Dokumen ini digunakan untuk mencatat,
mengidentifikasi, dan mendokumentasikan
defect atau bug yang ditemukan selama
proses pengujian website Jetprint.id.

Setiap defect akan dicatat berdasarkan
hasil pengujian aktual dan evidence
yang diperoleh selama proses testing.

## 5. Defect Status

| Status | Description |
|---|---|
| Open | Defect telah dilaporkan dan belum diperbaiki |
| Fixed | Developer menyatakan defect telah diperbaiki |
| Retest | Defect sedang diuji ulang |
| Closed | Defect telah diverifikasi dan dinyatakan selesai |
| Reopened | Defect masih terjadi setelah perbaikan |

## 6. Severity Classification

| Severity | Description |
|---|---|
| Critical | Masalah sangat serius yang menghambat fungsi utama |
| High | Masalah besar yang mengganggu fungsi penting |
| Medium | Masalah yang mengganggu sebagian fungsi |
| Low | Masalah kecil dengan dampak terbatas |

## 7. Evidence Documentation

## 8. Notes

Defect hanya akan dicatat apabila ditemukan
dan diverifikasi berdasarkan hasil pengujian.

Hasil Fail pada test case akan dianalisis
terlebih dahulu sebelum ditetapkan sebagai
defect.

Apabila tidak ditemukan defect selama
pengujian, kondisi tersebut akan dicatat
sesuai hasil aktual pengujian.
