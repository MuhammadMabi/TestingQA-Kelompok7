# Supporting Journals

## 1. Tujuan

Dokumen ini berisi jurnal dan publikasi ilmiah yang digunakan sebagai referensi pendukung dalam pengujian website Jetprint.id.

Referensi pendukung digunakan untuk melengkapi standar ISO/IEC/IEEE 29119 serta memberikan contoh penerapan metode dan teknik software testing pada penelitian terbaru.

## 2. Kriteria Referensi

Referensi yang digunakan harus memenuhi kriteria berikut:

- Tahun publikasi 2023–2026.
- Berasal dari jurnal, prosiding, atau publikasi akademik yang dapat diverifikasi.
- Berkaitan dengan Software Testing atau Software Quality Assurance.
- Relevan dengan metode atau teknik pengujian yang digunakan.
- Memiliki sumber publikasi yang dapat diverifikasi.
- DOI atau URL publikasi dicantumkan apabila tersedia.

## 3. Topik Referensi

Pencarian referensi difokuskan pada:

1. Software Testing.
2. Software Quality Assurance.
3. Black Box Testing.
4. Functional Testing.
5. Equivalence Partitioning.
6. Boundary Value Analysis.
7. Web Application Testing.
8. E-Commerce Testing.
